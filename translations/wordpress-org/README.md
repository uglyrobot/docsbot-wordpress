# WordPress.org listing translations

These PO catalogs translate the public WordPress.org plugin listing generated
from `docsbot/readme.txt`. They are separate from the runtime catalogs bundled
in `docsbot/languages`.

Each catalog is an import-ready translation draft for the matching
WordPress.org **Stable Readme (latest release)** project. WordPress.org does not
accept unreviewed machine translations as approved translations. A native
speaker and the locale's translation editors must review these drafts before
they are published.

When the DocsBot plugin directory project is available:

1. Open the locale's Stable Readme project on translate.wordpress.org.
2. Import the matching `readme-LOCALE.po` file.
3. Review every imported string for terminology, tone, links, and product names.
4. Ask the locale's translation editors to approve the reviewed strings.

The plugin name and DocsBot, WordPress, and integration product names remain
untranslated.
